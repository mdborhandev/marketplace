# PoshakGhor

Architecture and technical scaffolding for a Bangladesh-focused multi-vendor fashion marketplace. The application is a layered monolith targeting .NET 10: one ASP.NET Core host serves Razor MVC and the future versioned REST API.

See [Architecture](docs/ARCHITECTURE.md), [Project Structure](docs/PROJECT_STRUCTURE.md), and [Development Guidelines](docs/DEVELOPMENT_GUIDELINES.md) to get started. This phase intentionally contains no marketplace business functionality.
